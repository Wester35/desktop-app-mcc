# Руководство пользователя — DesktopAppMCC

## 🔑 Авторизация

После установки и запуска приложения в окне авторизации требуется войти под учетными данными:
- Логин: admin  
- Пароль: admin

После входа откроется главное окно с кнопками, открывающими различные разделы системы.  
В окне «Профиль» можно изменить пароль и просмотреть данные учетной записи.

---

## ⚙️ Порядок работы при вычислениях

1. Ввод данных.
2. Расчет интегральных показателей.
3. Построение интегральной модели.
4. Построение интервальной модели.

---

## 📊 Предварительный анализ (ДО построения моделей)

На начальном этапе необходимо осуществить вычисление матрицы корреляции.  
Далее отобрать те значения парных коэффициентов корреляции между ФАКТОРАМИ, которые больше 0.6.  
Далее необходимо определить, какой из них не будет включен в модель.  
Смотрим, у кого из них сильнее влияние на результативный показатель (тоже по парному коэффициенту корреляции, но уже МЕЖДУ ФАКТОРОМ И ИГРЕКОМ).  
Соответственно, в модель будет включен тот фактор, у кого корреляция с игреком больше.  
Эта процедура осуществляется в ручном режиме самим исследователем.  
После этого можно перейти к расчетам моделей.

---

## 🧮 Инструкция по построению моделей

- Откройте соответствующее окно модели (Интегральная / Интервальная).
- Выберите нужные факторы галочками или используйте автоматический режим.
- Нажмите «Построить регрессию» для выполнения расчета.
- После расчета программа выведет уравнение регрессии, коэффициенты и статистические показатели:
  - R² — коэффициент детерминации (доля объясненной вариации).
  - Fфакт и Fкр — проверка статистической значимости модели.
  - t-значения — проверка значимости отдельных факторов.

---

## 📈 Просмотр графиков

В разделе «Графики» доступны результаты визуализации регрессионных моделей:
- Интегральные графики.
- Среднесуточные графики.

Если отображается сообщение «Не выполнены предыдущие шаги» — выполните расчеты моделей заново.

---

## 🧾 Прогнозирование

Откройте окно «Прогнозы», чтобы просмотреть результаты моделей. Сами уравнения сохраняются скрытно.

---

## 👥 Работа с пользователями

- Новые пользователи регистрируются через кнопку «Регистрация».
- Главный администратор (логин admin) может добавлять других администраторов.
- Остальные администраторы могут регистрировать обычных пользователей.

---

## 🚪 Выход из системы

- Кнопка «Выход» завершает текущую сессию и при необходимости удаляет сохранённые данные входа.
- При следующем запуске потребуется повторная авторизация.
